# AI Trading Bot — Binance Futures Testnet

## 📌 Overview

This project is a modular **CLI-based AI Trading Bot** built in Python that interacts with **Binance Futures Testnet API** to place orders.

The goal of this project is to demonstrate:

* Clean backend architecture
* API integration
* CLI design
* Logging & validation
* Production-style project structure

The bot allows users to place market orders from the command line using validated inputs.

---

## 🧱 Project Architecture

```
trading_bot/
│
├── bot/
│   ├── client.py        # Handles Binance API requests & signing
│   ├── orders.py        # Order creation logic
│   ├── validators.py    # Input validation
│   └── logging_config.py # Logging setup
│
├── cli.py               # CLI entry point
├── requirements.txt
├── README.md
└── logs/
```

---

## ⚙️ Features

* Binance Futures Testnet integration
* HMAC SHA256 request signing
* CLI-based order placement
* Structured logging
* Modular design (production style)
* Input validation layer

## 🔑 Environment Setup

Create a `.env` file in the root directory:

```
BINANCE_API_KEY=your_testnet_key
BINANCE_API_SECRET=your_testnet_secret
```

Note: Valid **Binance Futures Testnet** API keys are required.

---

## ▶️ Installation

Create virtual environment:

```
python -m venv .venv
.venv\Scripts\activate
```

Install dependencies:

```
pip install -r requirements.txt
```

---

## 🚀 How to Run

Example command:

```
python cli.py BTCUSDT BUY MARKET 0.001
```

Arguments:

* SYMBOL → Trading pair (e.g., BTCUSDT)
* SIDE → BUY / SELL
* ORDER_TYPE → MARKET
* QUANTITY → Order size

---
